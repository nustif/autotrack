# AutoTrack

Aplicație web (PWA) pentru costuri și venituri auto: alimentări, cheltuieli, venituri, ore lucrate, documente și rapoarte pe perioadă.

Site: https://nustif.github.io/autotrack/

- Datele se păstrează doar în browserul/telefonul tău (localStorage). Fă backup periodic din Setări.
- Pe iPhone: deschide site-ul în Safari → Partajează → Adaugă pe ecranul principal.
